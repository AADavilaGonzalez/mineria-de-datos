# Resumen de la práctica 1

En esta práctica se selecciona el **Bike Sharing Dataset** como fuente de datos
para el proyecto. El conjunto contiene registros horarios de alquiler de
bicicletas realizados durante 2011 y 2012.

También se comprueba que el dataset cumpla con los requisitos solicitados:

- Contiene más de 5,000 registros.
- Incluye variables numéricas como temperatura, humedad y cantidad de
  alquileres.
- Contiene variables categóricas como temporada y situación meteorológica.
- Incluye una variable de fecha (`dteday`) que permite analizar la evolución
  temporal de los alquileres.
- Está concentrado en un solo archivo CSV.

La práctica funciona como una descripción inicial del dataset y justifica que
es adecuado para aplicar técnicas de análisis descriptivo, visualización,
regresión, clasificación, agrupamiento y series de tiempo.
