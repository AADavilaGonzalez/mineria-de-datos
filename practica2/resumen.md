# Resumen de la práctica 2

Esta práctica realiza un análisis descriptivo del Bike Sharing Dataset. El
programa carga el archivo CSV, valida que contenga las columnas esperadas y
convierte la fecha a un formato que pueda ser utilizado correctamente.

Para las variables numéricas calcula y muestra:

- Número de registros.
- Media, mediana y moda.
- Valores mínimo y máximo.
- Desviación estándar.

También analiza la distribución de variables categóricas como la temporada, el
año, el mes, la hora, el día de la semana y la situación meteorológica. Para
facilitar la lectura, algunos códigos numéricos se muestran con etiquetas
descriptivas.

Finalmente, el programa describe las relaciones principales del dataset,
comprueba que `cnt` sea igual a la suma de usuarios casuales y registrados, y
calcula las correlaciones más fuertes con el total de alquileres. Estas
correlaciones sirven como una primera aproximación para identificar variables
relevantes, aunque no implican causalidad.
